# AURA Autumn — Интернет‑магазин на Next.js

**Стек:** Next.js 16 (App Router), React, TypeScript, Zustand, Vercel.

**Что реализовано:**
- **Каталог и фильтрация:** серверная страница каталога + клиентские фильтры через `searchParams`.
- **Корзина:** управление состоянием на Zustand с учётом вариаций (размер), сохранение в `localStorage`.
- **Архитектура:** разделение серверных и клиентских компонентов, модульная структура (типы в `lib/types.ts`).
- **Деплой:** Production на Vercel с постоянным алиасом.

**Статус:** MVP. Данные хранятся в моках; для продакшена планируется интеграция с бэкендом.

**Ссылка:** https://aura-tan-omega.vercel.app
